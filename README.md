# barokah-tunas-unggul
UD. Barokah Tunas Unggul merupakan usaha yang bergerak dalam pengolahan dan produksi kopi bubuk dengan merek Kopi Onggu. Kami mengembangkan produk kopi yang mengedepankan kualitas bahan baku, ketelitian dalam proses sortasi, serta karakter pengolahan tradisional yang menjadi identitas produk.
